Consideraciones de Seguridad

Contraseñas seguras

Exigir contraseñas complejas y utilizar hash seguro (bcrypt) con salt para almacenamiento.

Autenticación de dos factores (2FA)

Implementar 2FA para acceso adicional seguro, especialmente para administradores.

Tokens JWT

Utilizar JSON Web Tokens para manejo de sesiones con expiración configurable.

Protección contra ataques

Implementar rate limiting, protección contra CSRF y sanitización de inputs.

Roles y permisos

Sistema de autorización basado en roles para controlar acceso a funcionalidades.

Consideraciones Técnicas

Almacenamiento seguro

Nunca almacenar contraseñas en texto plano. Usar hash con salt y algoritmos seguros.

HTTPS obligatorio

Todas las comunicaciones deben realizarse sobre HTTPS para proteger datos sensibles.

Validación de entrada

Validar y sanitizar todos los datos recibidos del cliente para prevenir inyecciones.

Cookies seguras

Configurar cookies con flags HttpOnly, Secure y SameSite para mayor seguridad.

Logs de auditoría

Mantener registros de intentos de login exitosos y fallidos para monitorización.

Recuperación de cuenta

Implementar flujo seguro para recuperación de contraseña con tokens temporales.

Tipos de Usuarios y Permisos

Estudiante

Acceso a simulaciones, ejercicios prácticos y visualización de su propio progreso.

Profesor

Gestión de clases, asignación de ejercicios, visualización de progreso de estudiantes.

Administrador

Gestión completa de usuarios, contenido, y configuración del sistema.

Invitado

Acceso limitado a demostraciones sin necesidad de crear cuenta.
